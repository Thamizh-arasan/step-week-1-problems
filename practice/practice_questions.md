# Day 1 Live-Coding Session — Practice Problems

## 1. Rock-Paper-Scissors Game
Create a Rock-Paper-Scissors game where the computer generates a random move and the player enters a move. Play N rounds (suggested: 5), display the result of each round, and show a summary table with wins, losses, draws, and win percentage.

Suggested method:
`String playRound(String playerMove, String computerMove)`

## 2. Palindrome Checker (3 Approaches)
Check whether a string is a palindrome using three approaches:
1. Iterative approach
2. Recursive approach
3. Array reversal approach

All three approaches should agree on the result.

Suggested methods:
- `isPalindromeIterative`
- `isPalindromeRecursive`
- `isPalindromeArrayReversal`

## 3. BMI Calculator for a Team
Accept arrays of heights and weights for team members. Calculate BMI for each member, determine the BMI status using the required thresholds, and print a wellness report table.

Suggested methods:
- `getBmiStatus(double bmi)`
- `printWellnessReport(double[] heights, double[] weights)`

## 4. First Non-Repeating Character
Given a string, count the frequency of each character and find the first character whose frequency is 1.

Suggested method:
`char findFirstNonRepeatingChar(String text)`

## 5. Reverse Customer Name
Accept a customer name, reverse it, return the reversed name, and print both the original and reversed names.

Suggested method:
`String reverseCustomerName(String customerName)`
